# Pong - 2 Jogadores

Jogo clássico Pong desenvolvido em Python utilizando Pygame.

## Controles

- Jogador 1: W/A para subir e S/D para descer.
- Jogador 2: Setas direcionais.

## Funcionalidades

- Multiplayer local para dois jogadores.
- Placar.
- Aumento de velocidade a cada colisão.
- Sistema de vitória com 10 pontos.

## Instalação
